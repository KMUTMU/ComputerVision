## CIFAR-10 이미지 분류 (레벨 0)

사전학습 모델(ResNet/MobileNet 등)을 CIFAR-10에 미세조정하면서, 여러 하이퍼파라미터 조합을 자동으로 실행하는 심화 실험입니다. (3시간 목표)

| 파일 | 역할 |
|------|------|
| `train_transfer.py` | 전이학습 1회 실험 (모델/lr/옵티마이저 등 지정) |
| `run_overnight.py` | 여러 조합 자동 실행 (시간 추정 + 중단 복구) |
| `analyze_results.py` | 결과 순위표 + loss/정확도 곡선 그래프(PNG) |

### 실행 전 체크 ⚠️
- 전원 어댑터 연결 🔌
- 절전모드 "안 함"
- 노트북 덮개 닫아도 안 꺼지게 설정

### 사용법
```cmd
conda activate cv
pip install matplotlib            # 그래프용 (한 번만)
python run_overnight.py           # 밤새 여러 실험 자동 실행
```

아침에 일어나서:
```cmd
python analyze_results.py         # 순위표 + plots/ 폴더에 그래프 PNG
```

### 시간 조절
`run_overnight.py` 상단에서:
- `GRID` : 실험할 조합 (모델/옵티마이저/학습률)
- `COMMON["epochs"]` : 각 실험 에포크 수 (시간의 핵심 손잡이)
- `COMMON["batch-size"]` : VRAM 부족(OOM) 시 64 → 32로 줄이기
- `TIME_BUDGET_SEC` : 전체 시간 예산 (초과 예상 시 자동 중단, 다음 실행 때 이어서)

중단되어도 `results_transfer.csv` 에 기록된 실험은 다시 실행 시 자동으로 건너뜁니다.

# 📊 실험 결과 및 해석 (연구 노트)

이 섹션은 실제로 수행한 실험의 결과와 해석을 기록합니다. (환경: RTX 5060 Laptop GPU, Windows)

## 실험 1: CIFAR-10 기본 CNN (레벨 0 — 입문)

처음 밑바닥 CNN으로 학습률 0.01, 5 epoch 학습.

| 지표 | 값 |
|------|-----|
| 최종 테스트 정확도 | **68.30%** |
| 학습 시간 | 63.6초 |
| loss 변화 | 1.89 → 0.90 (에포크마다 감소) |

**해석:** loss가 매 에포크 감소 = 모델이 정상적으로 학습(피드백받아 수정)됨.
10개 클래스 랜덤(10%) 대비 68%는 간단한 CNN + 5 epoch치고 양호. 이후 전이학습으로 크게 향상됨.

## 실험 2: 밤샘 전이학습 그리드 서치 (레벨 0 — 심화)

사전학습 ResNet18 / MobileNetV3-small을 CIFAR-10에 미세조정.
학습률 × 옵티마이저 × 모델 조합 8개를 자동 실행 (각 12 epoch).

| 순위 | model | optimizer | lr | best(%) | 시간(s) |
|------|-------|-----------|-----|---------|---------|
| 🥇 1 | resnet18 | sgd | 0.01 | **96.54** | 954 |
| 🥈 2 | mobilenet_v3_small | sgd | 0.01 | 96.01 | 714 |
| 🥉 3 | mobilenet_v3_small | adamw | 0.001 | 95.98 | 720 |
| 4 | resnet18 | sgd | 0.001 | 95.56 | 905 |
| 5 | resnet18 | adamw | 0.001 | 95.48 | 910 |
| 6 | mobilenet_v3_small | sgd | 0.001 | 94.25 | 715 |
| 7 | mobilenet_v3_small | adamw | 0.01 | 91.70 | 721 |
| 8 | resnet18 | adamw | 0.01 | **87.76** | 905 |

**핵심 해석:**
1. **전이학습의 위력**: 밑바닥 CNN(68%) → 전이학습(최고 96.54%), 약 28%p 향상.
2. **옵티마이저마다 최적 학습률이 다르다** ⭐
   - SGD는 lr=0.01에서 최고 (96.54%)
   - AdamW는 lr=0.01에서 꼴찌(87.76%), lr=0.001에서 양호(95.48%)
   - → AdamW는 작은 학습률을 선호. "lr은 옵티마이저에 맞춰 조정해야 한다"는 교훈을 직접 확인.
3. **정확도 vs 속도 트레이드오프**: MobileNet이 ResNet18보다 ~25% 빠르면서 정확도는 비슷 → 효율적.

## 실험 3: 적대적 공격 — 화이트박스 (레벨 1)

논문 *"Improving Adversarial Transferability with Local Perturbation Augmentation"* (CVPR) 재현.
- 데이터: 공식 ImageNet 검증셋에서 1000개 서로 다른 클래스, ResNet-50이 올바르게 분류하는 이미지 선별 (논문과 동일)
- surrogate = 평가 모델 = ResNet-50 (화이트박스)
- 파라미터: ε=16/255, T=10, α=1.6/255, μ=1.0 (논문 4.1.4)

| 공격 | 공격 전 맞힘 | ASR (공격 성공률) |
|------|-------------|------------------|
| I-FGSM | 916장 | **100.00%** (916장 전부 오분류) |

**해석:**
- ASR = (공격 후 틀린 장수) / (공격 전 맞힌 장수). 높을수록 공격이 강함.
- 화이트박스(공격 만든 모델 = 평가 모델)에서는 ASR이 거의 100% → 공격이 완벽히 작동.
- 공격 전 정확도가 100%가 아닌 이유: 선별 후 PNG 저장/재로딩 과정의 미세한 픽셀 손실로
  경계선 이미지 일부(84장)가 재분류 시 틀려짐. ASR은 "공격 직전 맞힌 것"만 분모로 쓰므로 계산은 공정함.

## 실험 4: 적대적 전이성 — 블랙박스 (레벨 2 — 논문의 핵심)

ResNet-50(surrogate)에서 I-FGSM 공격을 한 번 생성 → 서로 다른 구조의 target 모델들에 통하는지 평가.

| target 모델 | 구조 계열 | ASR (전이성) | 비고 |
|------------|----------|-------------|------|
| resnet50 | CNN (자기 자신) | **100.00%** | 화이트박스 |
| resnext50 | CNN (ResNet 유사) | 80.48% | 전이 잘됨 |
| densenet121 | CNN | 71.93% | 전이 꽤됨 |
| convnext_t | CNN (신식) | 38.26% | 중간 |
| swin_t | Transformer | 27.92% | 낮음 |
| vit_b | Transformer (순수) | **10.76%** | 가장 낮음! |

**핵심 해석:**
1. **구조가 비슷할수록 전이가 잘 된다**: ResNeXt(80%)·DenseNet(72%)는 ResNet과 같은 CNN 계열이라 공격이 잘 옮겨감.
2. **CNN → ViT 전이는 극도로 어렵다**: ViT는 10.76%로 처참. CNN과 구조가 완전히 달라
   ResNet-50에 특화된 노이즈가 거의 통하지 않음.
3. **이것이 논문의 문제의식**: 기본 반복 공격(I-FGSM)은 surrogate 모델에 과적합되어 전이성이 낮음.
   LPAA는 이 전이 ASR(특히 ViT)을 높이는 것이 목표.

**논문 Table 1과 비교 (참고):** 논문의 발전된 공격은 ViT-B 전이 ASR이 훨씬 높음
(예: LPAA ≈ 58%). 기본 I-FGSM(10.76%) 대비 큰 격차가 곧 논문의 기여.

## 실험 5: LPAA 구현 및 재현 (레벨 3 — 논문 재현 성공 🏆)

논문 Algorithm 1을 직접 구현(`adversarial/lpaa.py`)하여, ResNet-50(surrogate)에서
생성한 LPAA 공격을 ViT-B로 전이시킨 결과. (동일 데이터 1000장, ε=16/255, T=10, N=20, p=0.95, β=35)

| target 모델 | I-FGSM ASR | **LPAA ASR** | 개선 |
|------------|-----------|-------------|------|
| resnet50 (화이트박스) | 100.00% | 100.00% | - |
| **vit_b (전이)** | 10.76% | **65.34%** | **+54.58%p** 🚀 |

**핵심 해석:**
1. **LPAA가 CNN→ViT 전이성을 극적으로 개선**: ViT-B ASR이 10.76% → 65.34%로 6배 넘게 상승.
   논문의 핵심 주장("subspace augmentation으로 surrogate 과적합을 완화")을 직접 재현.
2. **논문 수치와 근접**: 논문 Table 1의 LPAA+ViT-B ≈ 58.3% 대비 우리 결과 65.34% (±7%p).
   서로 다른 1000장 샘플 + GMI 초기화 근사 구현을 감안하면 경향·절대값 모두 잘 재현됨.
3. **왜 좋아지나**: I-FGSM은 ResNet-50 그래디언트만 따라가 ResNet에 특화된 노이즈를 만들지만,
   LPAA는 랜덤 마스크로 여러 subspace를 탐색하고 증강계수(β)로 범위를 넓혀
   더 일반화된(generalizable) 노이즈를 생성 → 구조가 다른 ViT에도 통함.
4. **비용**: LPAA는 매 스텝 N=20 subspace를 평가해 I-FGSM보다 ~20배 느림 (1000장 약 14분).

---

### 📐 논문과의 수치 차이 분석 (LPAA ViT-B: 논문 58.3% vs 우리 65.34%, +7%p)

재현값이 논문보다 7%p 높게 나온 원인을 가능성 높은 순으로 분석:

1. **이미지 선별 기준 차이 (가장 유력)** ⭐
   - 논문: "거의 모든 모델이 올바르게 분류하는" 이미지 선별 (4.1.1)
   - 우리: `prepare_imagenet.py`가 **ResNet-50 하나만** 맞히면 채택
   - → 우리 샘플엔 ViT가 상대적으로 약하게 맞히는 이미지가 섞여 공격이 더 쉽게 통함 → ASR↑
2. **데이터셋 샘플 차이**: 서로 다른 1000장. 샘플에 따라 ±3~5%p는 흔히 흔들림.
3. **GMI 초기화 근사 구현**: 논문의 GMI(Global Momentum Init)를 모멘텀 사전공격으로 근사 → 초기화가 더 강하면 ASR↑.
4. **모델 가중치 버전**: 같은 "ViT-B"라도 torchvision 가중치와 논문 가중치의 학습 방식 차이로 공격 저항력이 다를 수 있음.
5. **세부 구현 디테일**: 마스크 생성/그래디언트 정규화/clamp 순서 등 논문이 명시 안 한 부분의 추정.

**방향성 해석:** 차이가 "우리가 더 높은" 쪽 → "LPAA가 논문보다 우수"가 아니라
"우리 평가 설정이 공격에 더 유리했다"로 보는 것이 타당. (특히 1번 선별 기준)

**메타 교훈:** 같은 알고리즘도 데이터 선별·초기화·모델 버전 등 세부 설정에 따라 수치가 달라진다.
재현 연구에서는 이 차이를 인지하고 설정을 맞춰가며 검증하는 과정이 핵심.

**→ 검증 1 진행:** 선별 기준을 논문처럼 "여러 모델이 모두 맞히는 이미지"로 바꿔 ASR이 58%에 근접하는지 테스트 (아래 실험 6).

## 실험 6: 7%p 차이 원인 규명 (Ablation 수사)

변수를 하나씩 통제하며 7%p 차이의 원인을 추적. (surrogate=ResNet-50, target=ViT-B, 동일 조건)

| 검증 | 바꾼 변수 | ViT-B ASR | 판정 |
|------|----------|-----------|------|
| 기준 | (ResNet-50만 필터) | 65.34% | - |
| **검증 1** | 선별 기준 → ResNet+ViT 둘 다 맞힘 | 64.97% | 선별 기준 **무죄** (거의 안 변함) |
| **검증 3** | LPAA 초기화(PI) 끔 `--no-init` | **66.22%** | 초기화 **무죄** (끄니 오히려 ↑) |

**해석:**
1. **선별 기준(가설 1)은 주원인 아님**: ViT를 필터에 추가해도 ASR 거의 불변(65.34→64.97).
   선별 기준은 "ViT가 원래 맞히는 양"엔 영향을 줬지만 공격 성공률(ASR)엔 영향 미미.
2. **초기화(가설 3)도 주원인 아님 — 오히려 반전 발견** ⭐
   - 초기화를 꺼야 ASR이 살짝 올라감(64.97→66.22).
   - 논문에선 PI가 ASR을 **올려줘야** 하는데(Table 5), 우리 구현은 반대로 작동.
   - → **우리의 GMI 근사 구현이 논문과 다르게(ResNet 쪽으로 과적합되는 방향으로) 작동**하고 있음을 발견.
     이는 수치 차이의 원인이라기보다 **구현 개선이 필요한 지점**.
3. **남은 유력 용의자**: 데이터 샘플 분산, 모델 가중치 버전, LPA 본체(β=35 등)의 구현 디테일.
   특히 초기화 없이 LPA만으로도 66%가 나오므로 **LPA 본체가 강하게 작동**하는 것으로 보임.

**다음 조치:** GMI 초기화를 논문 방식에 맞게 정확히 재구현 → PI가 ASR을 올려주는 방향으로 작동하는지 확인 (실험 7).

**방법론 메모:** 이 과정은 ablation study(구성요소를 하나씩 제거해 기여도 측정)로,
논문 4.5절과 동일한 분석 기법. 변수를 통제하며 원인을 좁히는 것이 재현 연구의 핵심.

## 실험 7: 정식 GMI 재구현 + 수사 결론 (ViT-B)

GMI 공식 구현(`Omenzychen/Global-Momentum-Initialization`)을 분석해, 핵심 로직
(사전 수렴 + 증폭계수 amp=10 global search + 입력 리셋/모멘텀 유지)을 정확히 재구현.

| 초기화 설정 | ViT-B ASR |
|------------|-----------|
| 초기화 끔 (`--no-init`) | 66.22% |
| 초기화 켬 (근사 GMI) | 64.97% |
| **초기화 켬 (정식 GMI)** | **64.87%** |

**해석:**
1. **세 경우 모두 64~66% — 초기화는 이 설정에서 ASR에 거의 영향 없음.**
   정식 GMI로 고쳐도 변화 없음 → 초기화(가설 3) 완전히 배제.
2. **왜 논문(Table 5)과 다른가**: 논문의 PI 효과는 CNN/ViT/ATM 평균값. 특정 조합
   (RN-50→ViT-B)에서는 효과가 작을 수 있음. 또 β=35로 LPA 본체가 이미 매우 공격적이라
   ViT ASR이 65%로 높아 추가 상승 여지가 적음(천장효과).

### 🏁 7%p 차이 수사 — 최종 결론
| 용의자 | 검증 | 판정 |
|--------|------|------|
| ① 선별 기준 | 실험 6 (검증 1) | ❌ 무죄 (영향 없음) |
| ② 초기화(근사/정식) | 실험 6~7 | ❌ 무죄 (영향 없음) |
| ③ 데이터 샘플 분산 | 미검증 | 🔍 유력 |
| ④ 모델 가중치 버전 | 미검증 | 🔍 유력 |
| ⑤ LPA 본체 강도(β 등) | 미검증 | 🔍 유력 |

**결론:** 7%p 차이는 선별 기준·초기화가 아니라 **데이터 샘플 분산 + LPA 구현 강도**에서
기인한 것으로 판단. 초기화 없이 LPA만으로 66%가 나오는 점이 "LPA 본체가 강하게 작동함"을 뒷받침.

**연구적 의의:** 재현값과 논문값의 차이를 통제 실험(ablation)으로 체계적으로 추적하여
원인을 "데이터/구현 디테일"로 좁혔다. 단순 재현을 넘어 차이의 출처를 규명한 과정.

## 실험 8: 완전 재현 — 분야 표준 데이터셋 + timm 가중치 (ViT-B)

분야 표준 프레임워크(TransferAttack)의 세팅으로 맞춰 재실험:
- 데이터: 커뮤니티 표준 "ImageNet 호환 1000 PNG" (자체 선별본 대신)
- ViT 가중치: torchvision → **timm** (`vit_base_patch16_224`)

| 설정 | ViT-B ASR | 논문(58.3%)과 차이 |
|------|-----------|-------------------|
| 처음 (자체 데이터 + torchvision ViT) | 65.34% | +7.0%p |
| 완전 재현 (표준 데이터 + timm ViT) | **62.63%** | **+4.3%p** ⬇ |

**해석:**
1. **데이터·가중치를 표준으로 맞추니 ASR이 논문 쪽으로 2.7%p 수렴** (65.34→62.63).
   → 가설 ③(데이터 샘플 분산) + ④(모델 가중치 소스)가 차이의 원인이었음이 **확증**.
2. **남은 4.3%p의 주원인은 ⑤ LPA 구현 디테일**로 판단.
   데이터·가중치를 맞췄는데도 남은 차이이고, 초기화 없이 LPA만으로도 ASR이 높았던 점과 일관.
   (마스크 생성/clamp 순서/정규화 등 논문 미명시 부분을 우리가 추정 구현)
3. **완전히 동일한 데이터셋 보장 불가**: 받은 표준 1000장이 LPAA 저자가 쓴 바로 그 세트인지
   100% 확신할 수는 없음(일부 잔차 가능).

### 🏁 7%p 차이 — 최종 종결
| 용의자 | 판정 | 근거 |
|--------|------|------|
| ① 선별 기준 | 무죄 | ablation (실험 6) |
| ② 초기화 | 무죄 | ablation (실험 6~7) |
| ③ 데이터 샘플 | **유죄(일부)** | 표준 데이터로 ASR ↓ (실험 8) |
| ④ 모델 가중치 소스 | **유죄(일부)** | timm으로 ASR ↓ (실험 8) |
| ⑤ LPA 구현 디테일 | **주범(잔존)** | 데이터+가중치 맞춰도 4.3%p 잔존 |

**최종 결론:** LPAA의 핵심 효과(CNN→ViT 전이성 대폭 개선)는 완벽히 재현됨.
절대 수치 차이는 체계적 ablation으로 추적한 결과 "데이터·가중치 소스 + 구현 디테일"로
설명되며, 표준 세팅 적용으로 논문값에 4.3%p까지 근접(초기 7.0%p에서 개선).
