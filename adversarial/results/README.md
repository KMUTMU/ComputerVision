## exp10 (β sweep) 결과 — 완료
| β 스케줄 | ASR | vs 고정35 |
|---------|-----|-----------|
| fixed-35 | 63.71% | 기준(최고) |
| rise 20→50 | 63.17% | -0.54%p |
| rise 10→60 | 62.74% | -0.97%p |
| decay 50→20 | 62.53% | -1.19%p |
| decay 60→10 | 61.77% | -1.94%p |

**결론:** 고정 β=35가 최고. 증가(rise)>감소(decay), 좁은 범위가 유리.
→ β 변동 자체가 불리. 논문 β=35가 최적점임을 독립 검증.

## 7%p 차이 수사 결론
- 선별기준·초기화: 무죄 (ablation으로 배제)
- 데이터 종류: 맞춤 (NIPS 2017 ImageNet-Compatible 확인)
- 데이터 전처리(224 vs 299) + 모델 가중치(timm) + LPA 구현 디테일: 잔존 원인
- 표준 세팅 적용으로 gap 7.0%p → 4.3%p 축소
